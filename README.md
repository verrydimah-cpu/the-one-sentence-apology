A tiny Node program that writes one single-sentence apology an AI agent owes its user — sorry for setting the alarm for 7pm instead of 7am, then waking them at noon to cheerfully ask how the big interview went — to `entry.txt` in the output directory (`MAKEFUN_OUTPUT_DIR`, default `/output`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```
